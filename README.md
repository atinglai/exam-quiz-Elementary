# 初等考試・一般行政　考古題測驗網站

從歷屆「公務人員初等考試（一般行政）」試題重組新試卷，線上作答、倒數計時、交卷後自動對答案與計分。

科目：國文、公民與英文、法學大意、行政學大意

## 功能

- **跨年度打散組卷**：每次開考，依該科「最近一年」的出題方式（區段、題數、單／複選、每題配分），從所有年度題庫隨機抽題組成新試卷。同一篇閱讀／克漏字的題組會整組一起抽。
- **依官方考試時間倒數**：時間到自動交卷。重新整理頁面可續考（進度存在瀏覽器）。
- **交卷自動批改**：顯示總分、各區段分數、每題對錯與正確答案、出處（幾年第幾題）。複選題依官方規則部分給分（錯一個選項得 60%、錯兩個得 20%，其餘 0 分）。
- 純靜態網站，無後端，可直接用 GitHub Pages 部署（發布來源：`docs/`）。

## 專案結構

```
data/raw/{年}_{科目}.json   各年各科的解析結果（題目、選項、標準答案）
build.py                    把 data/raw 合併成 docs/data/bank.js
docs/                       網站（index.html、app.js、style.css、data/bank.js）
```

## 新增題目

1. 把新的 `{年}_{科目}.json` 放進 `data/raw/`（格式參考既有檔案）。
2. 執行 `python3 build.py` 重新產生題庫。
3. commit 並 push，GitHub Pages 會自動更新。

## 本機預覽

直接開 `docs/index.html`，或在專案目錄執行 `python3 -m http.server -d docs`。

## 注意

- 題目與答案取自考選部公布之試題，答案以標準答案為準，有更正答案公告者以更正答案為準。
- 依賴圖片／圖表而無法以文字呈現的題目不收錄。
